# deep_learning

This repository contains my personal solutions, implementation practice, and notes for the book **[Dive into Deep Learning (d2l)](https://d2l.ai/)**.

---

## 📖 About This Project

This project documents my learning journey through the D2L book. My goal is to bridge the gap between theoretical understanding and practical implementation using **PyTorch**.

Beyond just solving exercises, I focus on:

* **Modern Implementation**: Utilizing high-level PyTorch APIs (`nn.Module`, `DataLoader`, `optim`) to write clean, industry-standard code.
* **Dimensionality Tracking**: Deep dives into tensor shapes and matrix operations.
* **Practical Notes**: Debugging tips and explanations for common pitfalls I encountered during the exercises.
